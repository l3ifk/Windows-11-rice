## Window Cosmetics

**Mods:**

- Custom Window Corner Radius
- Maximized Window Margins

I like rounded corners so I use `Custom Window Corner Radius` for giving all applications neat corners with a `12px` radius corner. Additionally it allows windows to keep rounded corners while they're maximized or snapped. `Maximized Window Margins` just adds margins on all four sides.
